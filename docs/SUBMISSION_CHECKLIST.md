# Submission checklist

| Deliverable | Included | Status |
|---|---|---|
| Source repository content | Yes | Ready to upload to GitHub |
| End-to-end ML training and prediction | Yes | Implemented; run to verify in your environment |
| Dockerized application | Yes | Dockerfile and Compose provided |
| Live deployed system | No | Requires cloud credentials, deployment and public URL |
| CI workflow | Yes | Tests and Docker build on GitHub |
| CD workflow | Partial | Container publish; no cloud rollout |
| Automated retraining | Partial | Scheduled workflow plus local retraining; persistent shared data not wired |
| Experiment tracking | Yes | Local MLflow |
| Data drift monitoring | Yes | In-memory PSI drift endpoint/dashboard |
| Monitoring dashboard | Yes | Streamlit |
| Technical documentation | Yes | docs/TECHNICAL_DOCUMENTATION.md |
| Architecture diagram | Yes | architecture.mmd |

**Do not claim the platform is live in the cloud or fully production-grade until deployment and production safeguards are completed.**
